### 设计取向

- **清晰**：呈现决策所需的信息，让操作依据与数据含义可被理解。
- **克制**：缩短操作路径，让界面服务于任务本身。
- **细致**：持续打磨统计口径、平台兼容与交互体验。

**项目技术** &nbsp; `Rust` · `Tauri` · `React` · `TypeScript`
