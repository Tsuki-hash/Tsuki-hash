### Approach

- **Clarity** — Give decisions context. Make actions and numbers easy to understand.
- **Restraint** — Keep the path short and the interface focused on the task.
- **Care** — Refine the details, from usage calculations to compatibility and interaction.

**Built with** &nbsp; `Rust` · `Tauri` · `React` · `TypeScript`
